# Global Agent Rules: MIANE Project

## 1. Project Identity & Purpose
- **Project Name:** MIANE.
- **Core Functionality:** Smart travel itinerary planner and group expense-splitting application.
- **Design Philosophy:** Premium, cultural tech-minimalism balancing modern digital interfaces with rich, tactile travel environments. The vibe is liberating and energetic, avoiding the dryness of standard financial apps.

## 2. Global Tech Stack & Architecture
- **Architecture:** Distributed/Microservices.
- **Frontend:** Flutter (Mobile cross-platform).
- **Backend:** ASP.NET Core API + SQL Server.
- **AI Service:** Python (FastAPI) for AI Trip Planner & AI OCR receipt scanning.
- **Cloud/Infra:** Firebase (Auth, Push Notifications, Real-time sync).
